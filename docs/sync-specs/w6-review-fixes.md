# Engine fixes from the W4 threading review (2026-11-02), to do in W6

Static review of g_peersMtx threading after W4 (engine.cpp line numbers as of that review). The lock design itself was confirmed (scope, no natives under the lock, lock order, no dangling refs, keep-alive race-free).

1. **Major: cleanup unreachable after a session ends.** engine.cpp ~5382-5387 `if (mayChange && inScript) { if (!EnterServer()) return; }` returns before TickPeers/TickVehicles (~5627-5631); OnEnded sets g_entry Waiting and EnterServer returns false while disconnected. Remote peds and server vehicles stay frozen until a later session finishes entry; the `!s_syncLive` branch (~4081) is dead. Fix: when not in server mode and g_peers or g_vehs are non-empty, run a cleanup pass (SyncNet, delete gone/removed peds and vehicles, CommitNet) before the EnterServer gate.
2. **Major: vehicle interpolators survive a session boundary.** After a server restart the tick counter restarts low; OnWelcome never touches g_vehNet; OnVehicles un-removes reused ids; VehicleInterpolator::Push rejects the new low timeline as Stale (vehicle_drive.cpp ~211-215) for about the previous server uptime. Fix: in OnWelcome, inside the locked block, `interp.Clear()` and `haveState=false` for every g_vehNet entry (do not clear the map: that orphans g_vehs entities). Also give the interpolator a session id. Test: push snapshots at high tMs, simulate a new session, push low tMs -> accepted.
3. **Minor (W4 regression): OnWorld cancels the old ped's despawn.** OnJoined's id-reuse branch sets `pe.despawn = true` (~973); OnWorld then sets `g_peerNet[e.id].despawn = false` (~1051); SyncNet's epoch branch (~3524-3531) only resets look/kill/emote, so the new player drives the old player's ped and model. Fix: in SyncNet's `pe.netEpoch != n.epoch` branch set `pe.despawn = true; pe.respawnPed = true;`.
4. **Minor: data race on g_entryStarted** (`ULONG`, ~425) written by the join thread in OnEnded (~1009), read/written by the game thread in EnterServer (~1425-1427). Fix: `std::atomic<ULONG>`.

Nits (optional): Stop() has no caller; the keep-alive (100 ms) duplicates real states when server tickHz <= 6 (harmless); keep-alive repeats a moving player's velocity (check how the server treats a repeated non-idle sample); GageMP_Dispatch reads g_bus on the join worker unlocked while EventAdd/Remove mutate it (no in-tree caller of EventAdd).
