# Hero band: shot list

The band is driven by app state, not by scroll. One source of truth, `offset` (metres travelled inside the current period), feeds the camera, the world wrap, the sign slots and the traffic. The world repeats every P = 160 m (one gantry period; lamps every 40 m, lane dashes every 10 m), so wrapping `offset` is invisible: each wrap rotates the sign slots and repaints the far gantry.
